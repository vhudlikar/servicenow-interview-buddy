# ServiceNow Interview Buddy

An AI-powered ServiceNow interview preparation tool built using:

- Python
- Streamlit
- Ollama
- Llama 3.2

## Features

- Generate ServiceNow interview questions
- Role-based interview preparation
- Experience-based question generation
- Runs completely locally
- No API costs
- Works offline after model download

## Roles Supported

- Administrator
- Developer
- Consultant
- Architect

## Technologies Used

- Python
- Streamlit
- Ollama
- Llama 3.2

## Installation

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python -m streamlit run app.py
```
