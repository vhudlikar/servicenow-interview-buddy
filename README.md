# 🚀 ServiceNow Interview Buddy

An AI-powered ServiceNow interview preparation tool built with Streamlit, Ollama, and the open-weight Llama 3.2 model.

![Landing Page](screenshots/landing-page.png)

ServiceNow Interview Buddy is an AI-powered interview preparation tool built using Streamlit, Ollama, and the open-weight Llama 3.2 model.

The application helps ServiceNow professionals prepare for interviews by generating role-specific questions based on experience level.

## Features

✅ Generate ServiceNow interview questions

✅ Role-specific preparation:
- Administrator
- Developer
- Consultant
- Architect

✅ Experience-based question generation

✅ Runs locally using Ollama and Llama 3.2

✅ No API costs

✅ No external AI services required

✅ Works offline after model download

## Technology Stack

- Python
- Streamlit
- Ollama
- Llama 3.2

## Installation

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python -m streamlit run app.py
```

## How It Works

1. Select a ServiceNow role.
2. Select years of experience.
3. Click Generate Questions.
4. Receive personalized interview questions generated by a local AI model.

## Why Open Innovation Matters

The project is powered by an open-weight AI model running entirely on a local machine.

Benefits:

- No subscription costs
- Increased privacy
- No vendor lock-in
- Works without internet after setup
- Fully customizable
